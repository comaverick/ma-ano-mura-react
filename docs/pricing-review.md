# Pricing review — October 17, 2026

This review used a fresh SM public catalog collection (6,486 in-stock PHP products) and the official DA NCR daily PDF, followed by a full GitHub daily collection. Historical price rows were retained. Incorrect rows introduced during this review were corrected against the source before publication.
